\chapter{Introducción}



	Este documento contiene el análisis de requerimientos del proyecto ``{\em Sistema de control de Registros para la Restitución de Derechios de niños niñas ya adolescentes: (SICORRE)}'' que servirá como base para el análisis, diseño, construcción, pruebas y aceptación del proyecto.

%---------------------------------------------------------
\section{Presentación}

Como contexto la empresa fundación de restitución de derechos de niños niñas o adolescentes en estado de orfandad debido al feminicidio en México Nuevo León ha solicitado una propuesta de proyecto la cual tiene la finalidad de darle solución y estructura definida a procesos mecanizados que actualmente se realizan en papel, dichos procesos se definen como archivos, expedientes, diagnósticos, registro de fechas. Para lo cual en este documento se detalla el analisis del sitema propuesto. 

Este documento contiene la especificacion de los requerimientos del usuario y del sistema a desarrollar. Tiene como 
objetivo establecer la naturaleza y funciones del sistema para su evaluación y aprobación por la fundación interesada asi como futuras pruebas
Este documento corresponde al entregable C2-DT Documentacion de Analisis del proyecto.
