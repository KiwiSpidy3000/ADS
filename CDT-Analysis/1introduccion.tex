\chapter{Introducción}



	Este documento contiene el análisis de requerimientos del proyecto ``{\em Sistema de control de Registros para la Restitución de Derechos de niños, niñas y adolescentes: (SICORRE)}'' que servirá como base para el análisis, diseño, construcción, pruebas y aceptación del proyecto.

%---------------------------------------------------------
\section{Presentación}

Como contexto la empresa Fundación de Restitución de Derechos de Niños, Niñas y Adolescentes en estado de orfandad debido al feminicidio en México ha solicitado una propuesta de proyecto la cual tiene la finalidad de darle solución y estructura definida a procesos mecanizados que actualmente se realizan en papel, dichos procesos se definen como archivos, expedientes, diagnósticos, registro de fechas. Para lo cual en este documento se detalla el análisis del sistema propuesto. 

Este documento contiene la especificación de los requerimientos del usuario y del sistema a desarrollar. Tiene como 
objetivo establecer la naturaleza y funciones del sistema para su evaluación y aprobación por la Fundación interesada, así como futuras pruebas.
Este documento corresponde al entregable C2-DT Documentación de Análisis del proyecto.

Los requerimientos de usuario se identifican de la forma RUX donde:

\textbf{X} Es un número consecutivo: 1, 2, 3, ...

\textbf{RU} Lo identifica como \textbf{R}equerimiento de \textbf{U}suario.


Los casos de uso se identifican de la forma CUX, donde:

\textbf{X} Es un número consecutivo: 1, 2, 3, ...

\textbf{CU} Lo identifica como \textbf{C}aso de \textbf{U}so.

Las interfaces de usuario se identifican de la forma IUX, donde:

\textbf{X} Es un número consecutivo: 1, 2, 3, ...

\textbf{IU} La identifica como \textbf{I}nterfaz de \textbf{U}suario.

Los mensajes en pantalla se identifican de la forma MSGX, donde:

\textbf{X} Es un número consecutivo: 1, 2, 3, ...

\textbf{MSG} Lo identifica como mensaje abreviando la palabra en inglés \textbf{M}e\textbf{S}sa\textbf{G}e.
