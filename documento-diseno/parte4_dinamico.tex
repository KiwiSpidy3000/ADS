\section{Diseño Dinámico del CU: Login}

\subsection*{Descripción del Flujo}
El actor \textit{Usuario} ingresa sus credenciales; el sistema las valida contra la
base de datos y, según el resultado, otorga o deniega el acceso.

\subsection*{Flujo Alternativo / Excepciones}
\begin{itemize}
	\item Credenciales incorrectas: el sistema muestra mensaje de error y permite
	reintentar (máximo 3 intentos).
	\item Cuenta bloqueada: se redirige al flujo de recuperación de contraseña.
\end{itemize}
